第三扇门 / THE THIRD DOOR / PREVIEW 009
Unity 2022.3.62f3 / Windows / 中文与 English

启动 PlayDemo.cmd 或 TheThirdDoor.exe。
体验本版：在目录选择工作案例《事由的空白》，再点中文或 English 开始新局。
继续上次会保留那一局的规则。旧工作存档不会自动改成新版；家人案例仍使用第八版传话规则。

你替两位同事传话：先商量交稿与评审，再核对改过的通知，最后确定谁上传、谁发邀请。
门前回应只是接到话。你得走到收信人面前，把话真正送到。

WASD 移动 / 鼠标观察
E 在门前接话；00 长椅每场休息一次
F 在门前打开传话夹，选信封，再点“拆开组句”
Tab 手记与手牌 / V 本局拼贴长卷 / 滚轮或上下键阅读
F2 中英切换，保留草稿 / ESC 逐层返回或暂停
R 重玩 / 结局后空格收起纸面，看房间的变化

第一次在 01 或 02 按 E，会先打开牌组：九张里选五张。
可点留证、周旋、承接中的一套作为起点，再移除或加入单张牌。
五张全程可见，每张每场用一次。去 03 收场后，可换出一张，再确认下一场的手牌。
场中查看手牌不会补充次数。卡在 F 的组句页使用，不在门前回应时使用。

组句时先点的片段先说，最多两段；点已选片段可移除。
可搭配一张牌，也可不出牌。校样显示实际措辞与预期结果，确认才消耗资源。
取消、翻页和切换语言不花资源。已经听到的部分会保留。

余力：接话通常花 1。停顿、回执和休息能省下或恢复余力。
承重：没说完的安排、额外保证和接下的任务都会影响它。完整送达和交接能减轻负担。
直连：实际内容到达的程度，不代替本人同意。
每封通常有四次接话，代办可用第五次；交接本身不占新的接话次数。

可以尝试的配合
核对 → 原话：这封已核对，原话就不额外增加承重。
停顿 → 翻译：同一封话接着翻译，省一次余力，并留出两段工夫。
真实回执：带回已经发生的接话记录，返还本次接话余力；对面完整回执也能核对来源。
代办 → 交接：多花 1 余力整理清单，暂时承重 +3。送到后交回，卸下这件任务。

没有核对牌，也能回说话人门前按 F，用基本核对按钮。
没有交接牌，也能在收信人门前按 F，用基本交接按钮；基本动作需要余力。
第二场先认清新旧通知；第三场对方只能先听一件，注意开头顺序。
每场两边都接过话、两封公开安排送到、代办已交接，才可到 03 选择“进入下一场”。
收场恢复 2 余力、减 1 承重。最后一场还要各自确认安排。
如果先问了确认、后来才补送，回本人门前按 F，可以再问一次。
03 也允许提前离开，或在最后照当前这份安排收工。

自动保存包含场次、手牌、用过的次数、任务、版本、部分交付和原始记录。
回到目录可继续。拼贴长卷保留每一场实际说过的内容，不会把旧通知改写成新版。
