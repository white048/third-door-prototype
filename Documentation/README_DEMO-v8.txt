Unity 2022.3.62f3 / Windows / 中文与 English

运行 PlayDemo.cmd 或 TheThirdDoor.exe。
想体验第八版玩法，请开始一个新案例。继续旧存档会保留那局的旧规则；不会抹掉上次的进度。

你是两个人之间的信使。不是选一句最体贴的话就能结束这份差事：得把安排实际送到，还要应付不同的开头顺序、打断和有限的工夫。

WASD 移动 / 鼠标观察 / E 接话或休息
F 在门前打开传话夹；选信封，点“拆开组句”
先点的片段先说，最多两段。点已选片段可移除；可搭配一张卡。
看完校样再确认。取消不会消耗任何资源。
Tab 手记 / V 本局拼贴长卷 / 滚轮或上下箭头阅读
F2 随时中英切换 / ESC 逐层返回或暂停
G 获得重述后撤回上一次门前回应；实际送出的话不能擦掉
R 重玩 / 结局后空格收起纸面，继续看房间

每轮在 00 长椅可休息一次。两边的回应都结束会进入下一轮，送信本身不推进轮次。03 随时允许你考虑离开。
每封话通常最多四次接话；代偿可换第五次。没说完的部分可以分次补。动作卡和门前回应共用，每种只有一张。
私下那句可一直留在信封里。双方公开安排实际送达，同样能帮助你了解他们。
替人保证能换来暂定安排；那句保证并不是本人的同意，可以再用真实内容修正。
如果先问了确认、后来才补送，回说话人门前按 F，可再问一次安排。

会自动保存进行中的案例，返回目录可继续。新存档包含说话次序、听到的部分、接话次数、暂定安排与卡牌消耗。旧版进行中的存档继续按旧规则完成。
